# Отчёт о тестировании проекта LibraryApp

## Объект тестирования
Консольное приложение на C# (.NET 8) для учёта книг в библиотеке.
Реализует добавление книг, выдачу, возврат и поиск по идентификатору.
Классы: `Book` (модель книги), `Library` (хранилище и операции).

## Методика тестирования
- **Ручное тестирование** — прогон сценариев через `Main`.
- **Отладка в Visual Studio** — точки останова, пошаговое выполнение (F10/F11),
  окна «Локальные» и «Контрольные значения».
- **Статический анализ** — встроенные анализаторы .NET (`AnalysisLevel=latest`),
  предупреждения компилятора в окне «Список ошибок».

## Найденные дефекты

| ID | Описание | Шаги воспроизведения | Ожидаемый результат | Фактический результат | Статус |
|----|----------|----------------------|---------------------|-----------------------|--------|
| D1 | `NullReferenceException` при выдаче несуществующей книги | Запустить, вызвать `BorrowBook(999)` | Сообщение «Книга не найдена» | Исключение `NullReferenceException` | Исправлен |
| D2 | Повторная выдача уже выданной книги разрешена | `BorrowBook(1)` дважды | Второй вызов — отказ | Книга выдаётся повторно | Исправлен |
| D3 | Возврат невыданной книги меняет состояние | `ReturnBook(2)` для доступной книги | Сообщение «не была выдана» | `IsAvailable` без изменений, сообщение «возвращена» | Исправлен |
| D4 | `FindBook` падает при отсутствии книги | `FindBook(999)` | Возврат `null` | `InvalidOperationException` (First без default) | Исправлен |

## Результаты инспекции кода

| Замечание | Исправление |
|---|---|
| `FindBook` использовал `First()` вместо `FirstOrDefault()` | Заменено на `FirstOrDefault()` |
| Отсутствовали проверки на `null` | Добавлены `if (book is null)` |
| Нет проверки `IsAvailable` при выдаче | Добавлена проверка «уже выдана» |
| Нет проверки, что книга выдана, при возврате | Добавлена проверка `if (book.IsAvailable)` |
| Отсутствовала XML-документация публичных методов | Добавлены `<summary>` |
| `AddBook` не проверял входной параметр | Добавлен `ArgumentNullException.ThrowIfNull(book)` |
| Нарушений именования не выявлено | — |

## Итоги
После исправлений все 4 дефекта устранены, сборка проходит без предупреждений
(при `AnalysisLevel=latest`). Код соответствует стандартам именования,
публичные члены документированы, методы короткие и выполняют одну задачу.
Рекомендации: добавить модульные тесты (xUnit) на `Library`, включить
`TreatWarningsAsErrors=true` в CI.
